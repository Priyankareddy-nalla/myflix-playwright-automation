# myFlix E2E Test Automation
End-to-end test automation for the myFlix application using Playwright and JavaScript.

## About the Project
This project focuses on automating key user flows of the myFlix movie application to verify functionality and improve software quality.

## Technologies Used
- Playwright
- JavaScript
- Node.js
- Git and GitHub

## Automated Test Scenarios
- Login functionality
- Movie search
- Movie details
- User profile
- Profile update

## Test Automation Approach
- Page Object Model (POM)
- Locators and assertions
- Automated test execution
- Functional validation of user flows

## Project Purpose
This project is part of my continuous learning and practical development in software testing and test automation.
